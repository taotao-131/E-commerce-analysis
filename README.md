# 电商用户行为分析系统

## 1. 项目介绍

本项目基于淘宝用户行为公开数据，针对电商场景进行用户行为分析与可视化展示。

通过对用户浏览、收藏、加购、购买等行为数据进行分析，构建用户画像模型，挖掘用户价值，并利用 Streamlit 搭建交互式数据分析 Dashboard。

项目旨在帮助运营人员了解用户行为特征、商品热度以及用户转化情况，为精准运营提供数据支持。


---

## 2. 项目背景

在电商平台中，用户行为数据能够反映用户兴趣、购买意愿以及消费习惯。

本项目围绕以下业务问题展开：

- 用户整体活跃情况如何？
- 哪些商品受到用户关注？
- 用户从浏览到购买的转化情况如何？
- 哪些用户属于高价值用户？


---

## 3. 数据介绍

数据来源：

阿里天池公开数据集——淘宝用户行为数据。


数据规模：

- 用户行为记录：约1亿条
- 用户数量：约百万级


字段说明：

|字段|说明|
|-|-|
|user_id|用户ID|
|item_id|商品ID|
|category_id|商品类别ID|
|behavior|用户行为|
|timestamp|行为时间|


行为类型：

- pv：浏览
- fav：收藏
- cart：加购
- buy：购买

### （3）用户转化分析

---

### （4）用户价值画像

由于数据没有消费金额字段，因此采用行为价值模型：

指标：

- 行为频次
- 购买次数
- 用户活跃情况


用户划分：

|用户类型|说明|
|-|-|
|高价值用户|高频行为且购买次数较多|
|潜力用户|活跃度较高，有转化潜力|
|普通用户|低频用户|
